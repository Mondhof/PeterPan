一

秋日限定

把秋天做成作品带回家
01

秋日丰收花环

推荐秋日限定成品能挂家门口

在藤圈上粘松果、枫叶、干橙片和麦穗，做一个能挂在家门口的秋日花环。全场的花环挂满一面墙，就是现场最出片的打卡点。

怎么玩

  1. 老师展示几款秋日花环，讲配色和“疏密”的小窍门
  2. 挑选松果、枫叶、干橙片、麦穗，先在藤圈上摆出布局
  3. 用低温胶枪一样样固定，家长协助、老师看护
  4. 系上丝带和挂绳，把花环挂上作品墙合影

小的大的都能玩

5–7 岁

选 3–4 种材料，照老师示范的位置粘好

8–10 岁

自己设计配色和疏密，加上麦穗、丝带蝴蝶结等细节

拍照亮点
几十个花环挂满一面墙；孩子把花环举在脸前合影
场地需要
室内外均可，需要桌椅和电源（胶枪用），再准备一面能挂作品的墙或展架
02

「秋天的第一杯」香薰杯

秋日限定晶莹透明像开了一家小饮品店

把一杯香薰蜡烛做成「秋天的第一杯果茶」：杯里摆上干橙片、肉桂棒和“冰块”，倒入琥珀色的果冻蜡，凝固后就是一杯不会喝完的秋天。

怎么玩

  1. 选一只透明杯，想好要做“橙子果茶”还是“冰美式”
  2. 摆好干橙片、肉桂、蜡做的“冰块”等装饰，固定烛芯
  3. 老师统一倒入加热好的果冻蜡，孩子不碰热蜡
  4. 等待凝固时，给自己的饮品起名字、画杯贴、写一句“菜单介绍”

小的大的都能玩

5–7 岁

选 2–3 种装饰摆好，画一张杯贴

8–10 岁

设计配色和装饰位置，给饮品起名并上台介绍自己的“招牌饮品”

拍照亮点
一排“秋日饮品”摆在桌上，像一家小小饮品店
场地需要
室内，需要桌椅和电源（熔蜡用）；熔蜡和倒蜡全程由老师操作，成品要静置凝固后再带走
03

秋日落叶水晶球

秋日限定不用加热，最安全摇一摇落叶纷飞

在水晶球里搭一个秋日小森林：小蘑菇、小松鼠、小南瓜，再撒进枫叶亮片和金粉，一摇就是落叶纷飞。

怎么玩

  1. 挑选小摆件，在底座上搭出自己的秋日小场景
  2. 用胶把摆件固定在底座上
  3. 往球里加入清水、甘油、枫叶亮片和金粉
  4. 老师帮忙拧紧封口，摇一摇，看“落叶”慢慢飘下来

小的大的都能玩

5–7 岁

选 1–2 个摆件，撒入亮片

8–10 岁

自己设计场景故事、搭配多层摆件，给作品起名字

拍照亮点
孩子举起水晶球、对着光摇一摇的瞬间
场地需要
室内外均可，需要桌椅；全程不用加热

04

非遗皮影小剧场

非遗动手 + 开口表达

孩子自己画、剪、组装一个会动的皮影角色，再到幕布后面打着灯演一段小故事。不光动手，还要开口说。

怎么玩

  1. 听老师讲皮影的来历，看一段示范表演
  2. 在卡纸上画角色、涂色、剪下来
  3. 用两脚钉连好关节、插上竹签，角色就能动了
  4. 分组上台，在幕布后面表演

小的大的都能玩

5–7 岁

用印好的模板涂色、剪大轮廓，上台说一句台词

8–10 岁

自己设计角色、做可动关节，编一段小对白

拍照亮点
灯一亮，剪影投到幕布上：家长在幕前拍，孩子在幕后演
场地需要
室内或能遮光的角落，一个电源（接灯）
05

非遗漆扇

非遗最出片每把都独一无二

把漆滴在水面上，挑出流动的花纹，扇子一沉一转，花纹就印在了扇面上。

怎么玩

  1. 选好颜色，把漆滴到水面上
  2. 用竹签轻轻挑动，拉出纹路
  3. 扇面入水、旋转、提起
  4. 晾干后在扇面上写字、画点缀

小的大的都能玩

5–7 岁

选 1–2 种颜色，漂一次

8–10 岁

多色叠加、二次漂漆，再在扇面上手绘、题字

拍照亮点
扇子从水里提起来的那一下，全场都会“哇”
场地需要
户外或通风好的场地（漆有气味），需要几处放水盆的桌位
06

火漆印章 · 写给一年后的自己

新中式仪式感开口：读给家人听

孩子给一年后的自己写（或画）一封信，滴上火漆、按下印章封好，交给家长保管，明年再拆开。

怎么玩

  1. 写或画一封给一年后自己的信，不会写字就画
  2. 挑信封、配干花，把信装饰好
  3. 滴上火漆，按下印章封口
  4. 自愿上台，读一句“给一年后的我”

小的大的都能玩

5–7 岁

画一幅“一年后的我”，老师帮忙滴蜡，自己按印章

8–10 岁

写一段话，在老师看护下自己滴蜡、压印，再加干花装饰

拍照亮点
印章抬起、花纹出现的一瞬间；孩子举着封好的信合影
场地需要
室内外均可，需要桌椅和电源（火漆加热用），老师全程看护

参考流程

每场 2 小时，六个活动都按这个节奏，现场可按情况调整。

  1. 第 0–15 分钟签到入场，领取材料
  2. 第 15–30 分钟暖场：老师讲这个活动背后的小故事
  3. 第 30–90 分钟动手制作，老师分组指导
  4. 第 90–120 分钟作品展示、上台表演或分享，集体合影
